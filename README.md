# Seans Risk Makinesi (PropMatch)

Masaniello tabanlı seans risk hesaplayıcı. Prop hesabının toplam kayıp limitine göre seans kasasını belirler ve her işlemde kaç $ riske atılacağını, lot karşılığını hesaplar.

- Tek dosya: `index.html` (statik, build gerektirmez)
- Veriler tarayıcının localStorage'ında tutulur
- Varsayılan: 25.000$ bakiye, %7 limit, sabit 175$ seans kasası, 7 işlem / 2 kazanç, 1:2

Finansal tavsiye değildir.
